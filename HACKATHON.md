Problem 5: Automated Documentation Drift Detection

We will build a tool that analyzes code changes in pull requests, finds related documentation, and flags documentation that may have become outdated. It will connect each finding to the relevant documentation text and code change. We plan to use it to compare changed code with related documentation and flag possible mismatches for a developer to review.

AI model used and why

We chose Gemma 4 E2B because it can run locally through Ollama on our laptop and according to it's specifications.
